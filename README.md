# ANOMALYZE

Application de bureau pour explorer un dataset CSV et repérer ses anomalies.

## Fonctionnalités
- Chargement d'un fichier CSV et sélection des colonnes numériques
- KMeans avec choix automatique de k (score de silhouette)
- Projection PCA en 2D
- Détection d'anomalies avec Isolation Forest
- Visualisations : clustering, matrice de corrélation, anomalies
- Export des résultats (CSV) et des statistiques

## Installation
pip install numpy pandas matplotlib scikit-learn

## Lancement
Ouvrir `ANOMALYZE_v2.ipynb` et exécuter toutes les cellules.
